## Aciklama — Ingilizce

```
Learning to write code is one thing. Reading someone else's code and working
out what it actually does is another — and it is most of the job.

Rheo drills exactly that. Every question puts a small piece of code in front
of you and asks what it prints. You learn to trace line by line, to spot the
bug by eye, and to answer "what is happening here?" quickly.

HOW IT WORKS
• 10 chapters, 40+ lessons — from variables to graph algorithms
• Read-and-trace, bug hunt, fill the gap, reorder the lines
• A terminal view with the real output on every question
• Explanations that tell you why a wrong answer was wrong

THREE LANGUAGES
Python, JavaScript and Java, tracked separately so you can see where you
stand in each.

BUILT FOR THE HABIT
• Daily streak with a streak shield
• XP, levels, badges and daily goals
• Leagues and timed duels
• Daily quests and reward chests

NO INTERNET NEEDED
Everything ships inside the app. Works on the train, on a plane, off grid.

NO ACCOUNT
No signup, no login, no email. Open it and start. Your progress stays on your
device.

Rheo takes reading code as seriously as writing it.
```

## App Review notlari (Notes alanina)

```
Rheo bir kod okuma egzersiz uygulamasidir. Hesap veya giris gerektirmez,
tum icerik uygulamayla birlikte gelir ve internet baglantisi olmadan calisir.

Test icin: uygulamayi acin, kisa tanitimda hatali kod satirina dokunun,
gunluk hedefinizi secin. Ardindan yolculuk haritasindaki ilk dugume dokunup
START ile bir ders baslatabilirsiniz.

Uygulama ekranlarini cizmek icin paketin icinde gelen yerel bir HTML/JS
yigini kullanilir; bu yigin cihaz uzerinde yerel bir loopback sunucusundan
(127.0.0.1) servis edilir, uzak sunucudan icerik indirilmez. Info.plist'teki
NSAllowsLocalNetworking istisnasi yalnizca bu loopback icindir.
```
